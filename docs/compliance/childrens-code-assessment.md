# Children's Code check (ICO Age Appropriate Design Code)

DIAL IN is a general-audience trivia game that children are likely to play, so the ICO's Age Appropriate Design Code applies. This is our check against its 15 standards. **Reviewed 21 November 2026.**

| Standard | How DIAL IN meets it |
|---|---|
| 1. Best interests of the child | No ads, no tracking, no loot boxes. One optional £2.99 purchase with no pressure tactics. Short daily sessions. |
| 2. Data protection impact assessment | This document plus the legitimate interests assessment and the record of processing. Revisit before any feature that collects new data. |
| 3. Age-appropriate application | The same protective settings for everyone, so there's no need to know anyone's age. |
| 4. Transparency | Plain-English privacy notice, a short summary at the top, and in-game explanations where data is used (account card, board notes). |
| 5. Detrimental use of data | No profiling or recommendations. Streaks and reminders are mild and reminders are opt-in. **Watch:** keep streak and reminder wording gentle; no guilt messages. |
| 6. Policies and community standards | Display names are cleaned of symbols. **Gap to consider:** a simple way to report an offensive display name (privacy@ address for now). |
| 7. Default settings | High privacy by default: guests share nothing; reminders off; public boards only for players who choose to save an account. |
| 8. Data minimisation | No email, real name, age, location, contacts or photos. Username and PIN only, and the PIN is hashed. |
| 9. Data sharing | No selling or sharing. Processors only (Supabase, Cloudflare, Stripe, Resend until 5 Dec 2026). |
| 10. Geolocation | None collected. The fair-play tag is a scrambled IP hash, not a location, and is deleted after 48 hours. |
| 11. Parental controls | None in the game, so nothing hidden from parents. Parents can delete an account in Settings or by email. |
| 12. Profiling | None. |
| 13. Nudge techniques | No nudges to give more data. Account saving is optional; the only prompts are to protect a streak, which benefits the player. **Watch:** no countdowns or "only today" pressure on DIAL IN+. |
| 14. Connected toys and devices | Not applicable. |
| 15. Online tools | Export my data, Delete my account and data, and Sign out, all in Settings. Rights requests by email. |

**Actions:** add an in-game way to report a display name if Battles or Leagues grow; recheck this table whenever chat, photos, sharing or new purchases are considered.
