How to run a closest-number quiz

  • Everyone writes down a number for each question. No multiple choice, so nobody can guess at random.
  • Closest answer wins the round. For a fairer score, give points by how close people are: within 10% scores well, spot on scores best.
  • For years, count how many years off each guess is.
